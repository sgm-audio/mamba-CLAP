# MambaDAW: High-Performance AI Audio Processing CLAP Plugin

## Overview
MambaDAW is a CLAP audio plugin designed for high-performance AI audio processing using the Mamba State Space Model (SSM) architecture. The plugin implements a hybrid architecture where:
- **C++ Host**: Real-time audio processing using LibTorch for CPU inference
- **Python Training**: Model training and experimentation using PyTorch, torchaudio, librosa, and numpy

## Directory Structure
```
MambaDAW/
├── src/              # C++ source files for the plugin
├── include/          # C++ header files
├── python_training/  # Python scripts for model training and data processing
├── build/            # Build directory (generated by CMake)
├── resources/        # Resource files (presets, impulse responses, etc.)
├── CMakeLists.txt    # CMake build configuration
└── requirements.txt  # Python dependencies
```

## Build Instructions
### Prerequisites
- CMake 3.14 or later
- CLAP SDK (https://github.com/free-audio/clap)
- LibTorch (PyTorch C++ API) - Ensure compatibility with your system's C++ ABI
- C++17 compatible compiler

### Building
```bash
# Create and navigate to build directory
mkdir -p build && cd build

# Configure CMake (adjust paths if necessary)
cmake .. -DCMAKE_BUILD_TYPE=Release

# Build the plugin
cmake --build .

# The plugin (.clap file) will be generated in the build/release directory
```

## Hybrid Architecture
### C++ Host (Real-time Processing)
- Implements the CLAP plugin interface in `src/main.cpp`
- Uses LibTorch for efficient CPU inference of trained Mamba models
- Designed for low-latency audio processing in DAW environments

### Python Training (Model Development)
- Located in the `python_training/` directory
- Utilizes PyTorch for model definition and training
- Uses torchaudio for audio processing
- Employs librosa for audio feature extraction
- Leverages numpy for numerical operations

## Dependencies
### C++
- CLAP SDK
- LibTorch (with matching C++ ABI)

### Python (see requirements.txt)
- torch
- torchaudio
- librosa
- numpy
